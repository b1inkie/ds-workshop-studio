# DST 联机版功能核对

这是代码检查和离线测试状态，不代表真实 Steam 写入验收。真实上传、更新、删除仅由用户自测；助手不连接真实账号进行验证。

## 已接入

- Steam 初始化/账号状态、本人已发布物品分页查询、搜索、详情、中文/英文查询。
- 首次发布：文件/封面/作品信息必需，默认私密，创建 ID 后再提交。
- 更新：文件、封面、标题/简介/Tags 可分别选择；可见性始终提交。
- 15 个标准 Tags、自定义标签、去重、版本与兼容版本标签同步。
- 本地暂存、文件过滤、MNFS manifest、进度、超时提示、法律协议提示。
- 所有权与账号检查，一次性确认，写入中正常关闭保护。
- 同版本禁止上传文件；准备与提交均在后端检查，忽略 v 前缀/空白/大小写。仅改文字或封面不受限。不同版本不等于更高版本，目前不禁止回退版本。线上版本未知需额外确认。
- 本地版本编辑：仅唯一顶层静态 version 字符串，原文件备份、hash 冲突检查，不执行 Lua。
- DST 删除：预检、输入完整 ID、风险确认、提交前复查；结果未知不当成成功，不自动重试；保留本地文件和草稿。
- 按游戏/物品保存本机草稿，当前会话创建后失败可保留 ID 并切到更新。

## 尚未达到完整交付的部分

1. 真实 Steam 端到端验收缺失：浏览器测试模拟 IPC，Rust 测试校验局部逻辑/ABI，并不证明真实 CreateItem、SubmitItemUpdate、DeleteItem 已正常工作。
2. Lua 静态读取有限：不计算动态表达式/多语言分支；缺失名称和简介时需手动填写。没有完整 Lua 解释器，这是有意的安全边界。
3. 暂未自动提取 server_filter_tags、client_only_mod、server_only_mod、all_clients_require_mod；现阶段可在自定义 Tags 手动补充。
4. 线上 Tags 通过查询结构体读取；过长会截断并告警，更新预检拒绝截断的 Tags。按 GetQueryUGCNumTags/GetQueryUGCTag 逐项完整读取的增强尚未实现。
5. 上传历史虽写入本地 JSON，但没有历史/重启恢复界面；异常退出后需自行记录 ID、刷新核对，再选择已有物品，不能盲目重复新建。
6. 暂存使用 RAII 正常清理，进程崩溃/被杀可能遗留缓存；尚无过期缓存整理入口。
7. 提交成功后需手动刷新核对；法律协议仅文字提醒，暂无直达工坊页入口；本地封面暂无选择后预览。
8. 日志和草稿暂无导出、INI 配置导入导出与命令行模式。
9. 查询每种类型最多 20 页（1000 项）；暂存限制 10 万文件/4GiB，封面不超过 1MiB。
10. 交付为 exe 与同级 resources 便携目录，依赖系统 WebView2 和 Steam，尚无安装包/运行时引导/签名及干净环境验收。

## 用户手动验收建议（专用私密测试物品）

- 新建：文件、封面、中文标题/简介、Tags、版本正确；刷新后核对。
- 更新文件：升版本；线上文字和非版本 Tags 保留。
- 仅文字/Tags、仅封面：不上传内容，文件版本不变。
- 同版本：普通/带 v 前缀/空白/大小写等价时硬性拒绝，无强制覆盖。
- 取消准备/取消删除：无线上写入。
- 创建后失败：记录已有 ID，继续更新同一物品，不能重复创建。
- 删除：仅专用物品，核对 ID 后自测；未知结果先刷新，不自动重试。

结论：基础业务闭环已接入，属于待真实验收的功能测试版，不是已完整验收的正式版。

Workshop Studio · 饥荒创意工坊工具
版本：由发布包名称标明（功能测试版）

一、如何启动
1. 完整解压 ZIP 到普通文件夹，不要直接在压缩包内运行。
2. 双击 Workshop Studio.exe。
3. resources 文件夹必须与 exe 同级；其中的 steam_api.dll 不可删除或单独移动。
4. 手动替换文件前，请先关闭正在运行的程序，再整体替换程序及 resources 文件夹。请先备份自己的模组文件。

二、运行条件
- Windows 10 / 11。当前程序和 Steam DLL 均为 x86，可在常见 x64 Windows 上运行；其他环境未验收。
- 已安装 Microsoft Edge WebView2 Runtime。如缺少，请仅从微软官网下载并安装：
  https://developer.microsoft.com/microsoft-edge/webview2/
- Steam 客户端已启动并在线登录；账号应拥有对应游戏及模组工具的使用权限。
- Steam 初始化失败时，检查 Steam 登录状态及 Don't Starve Mod Tools（AppID 245850）。
- 无须安装 Node.js、Rust 或开发工具。
- 当前未做代码签名，Windows 可能提示未知发布者。仅使用可信来源的压缩包，勿关闭安全软件。

三、当前功能
- 饥荒联机版（DST，322330）及单机版（DS，219740）的本人作品查询。
- 新建发布、按范围更新、删除。上述真实写入流程仍需使用者在测试物品上验收。
- 标准和自定义 Tags、本地草稿、模组目录读取、版本编辑、运行日志。
- 只能修改自己拥有的作品；不要把正式作品当测试物品。

四、首次发布
1. 启动 Steam，选择游戏，点击“发布新模组”。
2. 读取含 modinfo.lua 的模组目录，核对标题、简介、Tags 和版本。
3. 选择不超过 1MiB 的 PNG/JPG/GIF 封面，建议先选择“私密”。
4. 点击“准备首次发布”：此阶段只生成本地快照并读取线上状态，不提交工坊。
5. 在确认窗口核对游戏、作品、文件及可见性，勾选确认后再提交。
6. 发布后刷新工坊，并在 Steam 中自行核对模组内容。

五、更新和版本
- 从列表选择正确作品，核对工坊 ID，再选择更新范围（文件、封面、标题/简介/Tags）。
- 可见性每次提交都会更新，请务必核对。
- 上传文件时，本地与线上版本相同会被硬性禁止；忽略 v 前缀、空白及大小写，不支持强制覆盖。
- 只改简介或封面、不上传文件时不受文件版本限制。线上版本未知时需额外确认。
- 可在“修改本地版本号”中输入新版本，再点“保存版本到文件”。
  此操作会修改源目录 modinfo.lua，并先备份到该模组的 .workshop-studio-backups 文件夹。
- 仅安全修改唯一顶层独立 version 字符串；动态表达式、重复定义或文件冲突会拒绝保存。
- 不执行 Lua；动态名称、简介、多语言条件等需要手动核对。

六、删除与失败处理
- 删除前需核对游戏及作品，输入完整工坊 ID，并明确确认风险。
- 线上删除不能在本工具内撤销；本地文件和草稿保留。
- 删除确认成功后自动刷新列表，刷新失败会单独提示。
- “结果未知”不等于失败：请先刷新或在 Steam 核对，不要立即重复新建、提交或删除。
- 如果新建过程中已经取得工坊 ID，请保存该 ID，后续更新该物品，避免重复创建。
- 上传或删除期间不要强制结束进程；无取消远端请求或事务回滚保证。
- 需要接受 Workshop 法律协议时，请在 Steam 页面处理。

七、已知限制（请阅读后再试用）
- 这是功能测试版，不是已经在不同电脑及真实账号上完整验收的正式版。
- 单机版采用 ZIP / Steam Cloud / RemoteStorage：ZIP 最大 100MiB，封面最大 1MiB。
- 单机版仅显示阶段进度，不提交更新说明；Cloud 暂存文件暂无自动清理，会占用配额。
- 超长线上 Tags 可能被旧接口截断，工具会告警或拒绝更新；部分 Lua 特殊 Tags 暂不自动提取。
- 成功上传后需手动刷新；没有重启后的历史恢复界面，异常退出可能遗留本地缓存。
- 草稿保存在当前 Windows 用户的应用数据中，不是备份；换电脑或清除 WebView 数据不会自动迁移。
- 暂无 INI 配置导入导出、命令行模式；部分设置项为占位。
- 无安装器、运行时引导；程序签名和干净电脑兼容性尚未验收。在工具内更新需开发者提供更新源后可用。

八、隐私与发布包
- 正常使用 Steam 服务会通过 Steam 客户端与 Steam 通信；工具界面也可能读取线上封面。
- 发布包不包含开发者的草稿、日志、账号信息、截图或诊断副本。
- steam_api.dll 为第三方 Steamworks 组件；公开再分发前，发布者须核对 Valve/Steamworks 的适用授权。
- 随包 SHA256 校验值用于检查文件完整性，不代表数字签名或安全软件认证。

十、在工具内更新
- 左侧活动栏底部“设置”可检查新版本；发现新版本时可“下载并安装”。
- 更新包经过完整性校验（SHA256）后才写入；安装完成后需重启生效，重启前旧版本仍可继续使用。
- 更新后程序目录可能出现“Workshop Studio.old.exe”旧版本备份，下次启动时自动清理，也可手动删除。
- 更新需联网；若更新源尚未配置或下载失败，不影响现有版本使用。
- 更新不会触碰你的模组文件、草稿或 Steam 数据。
